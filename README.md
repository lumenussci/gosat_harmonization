Code to 1) collocate GOSAT to OCO-2, 2) harmonize GOSAT to OCO-2, and 3) evaluate the harmonized GOSAT to OCO-2 and TCCON. A good portion of this code is based on Tommy Taylor's collocation, harmonization, and evaluation code.  


**Main_1_collocate_gosat_to_oco2_parallel** collocates single GOSAT soundings to a collection of OCO-2 soundings. The GOSAT and OCO-2 directories must be defined along with the collocation parameters. The resulting file is a netcdf file which is composed of single GOSAT soundings paired with the aggregated collocated OCO-2 soundings. **Run this on OCO Master.** 

**Main_1_tccon_collocation_parallel** collocates single GOSAT soundings (or OCO-2 soundings) to a collection of TCCON soundings. The GOSAT/OCO-2 and TCCON directories must be defined along with the collocation parameters. The resulting file is a netcdf file which contains the GOSAT/OCO-2 soundings paired with the aggregated collocated TCCON soundings. **Run this on OCO Master.**

**Main_2_feature_importance_analysis** take the collocated netcdf and determines the ranking of the most important features for performing the harmonization. When determining the feature importance ranking, all features that are highly correlated are evaluated and the feature that leads to the best performing model is kept while the others are discarded. The result of this file are plots indicating how model performance improves as features are sequentially added to the model in order of importance. The plots should inform which features to use for the harmonization in main_3_harmonization_and_eval.ipynb. 

**Main_2_gosat_colloc_to_oco2_exploratory_analysis** recreates some of the plots in Tommy's harmonization slide deck.

**Main_3_harmonization_and_eval** performs the harmonization of GOSAT to OCO-2 soundings. The script uses the collocated GOSAT and OCO-2 netcdf file generated by main_1_collocate_gosat_to_oco2_parallel and generates the harmonized GOSAT soundings. Tuning of the models takes place in this script as does the initial model evaluation. 

**Main_4_apply_model_to_full_gosat_record** applies the harmonization models developed in main_3_harmonization_and_eval to the full GOSAT record. The features used for the harmonization models must be specified in this file in the same order they appear in main_3_harmonization_and_eval. The resulting file is a netcdf which contains the harmonized full GOSAT record. **Run this on OCO Master.** 

**Main_4_apply_model_to_gosat_collocated_with_other_instrument** applies the harmonization models developed in main_3_harmonization_and_eval to GOSAT soundings that are collocated to either OCO-2 or TCCON. The features used for the harmonization models must be specified in this file in the same order they appear in main_3_harmonization_and_eval. The resulting file is a netcdf which contains the harmonized GOSAT soundings and the corresponding aggregated OCO-2/TCCON collocations. **Run this on OCO Master.** 

**Main_5_tccon_box_plots** generates TCCON-GOSAT collocation plots for spatial validation, one-to-one TCCON-GOSAT (BC & harmonized) plots, and box and whisker plots for dXCO2 between GOSAT (apriori, BC, and harmonized) and TCCON soundings.   

**Main_5_uncertainty_evaluation** evaluates the uncertainty estimates for the harmonized GOSAT soundings. This script generates spatial plots and one-to-one plots for dXCO2 between the harmonized GOSAT soundings and OCO-2/TCCON.
